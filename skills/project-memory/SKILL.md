# Project Memory

| Need | Read |
|---|---|
| End of non-trivial work: does `CONTEXT.md` need a change? | `references/context-check.md` (format: `references/CONTEXT-FORMAT.md`) |
| Design: name or change domain concepts, states, rules, boundaries; write an ADR | `references/domain-modeling.md` |
| A user correction or repeated failure that should become a rule | `references/learn.md` |
| Create, review, or repair a skill | `references/skill-creator.md` |

Shared rules: record only evidenced facts. Propose changes to rules, skills, and `AGENTS.md`; the user approves them. Keep each fact in one place and link to it.
